# 实施基线记录（add-qcc-copilot-mvp · 1.1）

> 本文记录 design.md 的**建议实施基线**如何落地，区分「已知事实 / 实施建议 / 待补信息」及其影响。
> 本文不把未实测组合或正式评分细则标为已具备；规划文档完成不代表产品已运行通过。

## 1. 基线定位

- 产品行为以 8 个能力规格为准；design.md 中的 Python、本地 JSON 档案、PPTX、文件式汇总是**实施建议**，不是用户已批准的技术事实。
- 当前项目无既有产品代码或主规格；本变更为全新增量。
- 领域内核与宿主解耦：宿主（如 OpenCode）负责模型推理与来源访问，确定性工具负责契约、计算、状态、文件生成与检查。

## 2. 已知 / 建议 / 待补信息（及影响）

| 类别 | 内容 | 影响 |
|---|---|---|
| 已知 | C01–C10 产品共识、三维评奖视角（价值 / 推广 / QCC 遵循）、权重未定、双入口、按需启动 | 规则包按三维定性检查构建，不生成官方分数 |

| 待补 | 真实试点成员、周期、业务目标阈值（D06） | 本变更仅用 E01–E12 与样例验证能力，不虚构业务目标或试点收益 |

## 3. 首批支持组合

| 项 | 本次实测组合 | 状态 |
|---|---|---|
| 宿主 | OpenCode（当前会话） | 用于端到端链路验证（见 10.2 / E12） |
| 系统 | macOS（darwin） | 已实测 |
| 运行时 | CPython 3.14.6，标准库 | 已实测；要求 >=3.11 |
| PPTX 生成 | 内置 stdlib OOXML 生成器 | 已实测（产出可打开/可编辑文件） |
| PPT 渲染核验 | LibreOffice/soffice | **未安装 → 渲染检查受限/未执行**，明确不标为通过 |
| 其它 Agent / Windows / 企业模板 / 官方评分细则 | — | **未验证 / 未配置**，不作为支持声明 |

默认无后台监听（按需调用）；支持矩阵逐项记录版本与验证范围，未测组合与已端到端验证组合分开。

## 4. 来源与规则/模板适配清单

| 适配点 | 契约边界 | 当前实现 | 扩展方式 |
|---|---|---|---|
| 来源 | 统一 `sources_doc` 契约 | 本地文本/Markdown/CSV/JSON、Git 记录；远端资料由宿主读取后以统一 `content`/导出文件输入 | 新增适配器仍输出同一契约，不另建认证系统 |
| 方法规则 | `methods/method_profile_v1.json` | 三维初始规则，`official_scoring_configured=false`，无权重 | 正式细则作为规则包新版本，标来源与适用范围 |
| 报告/复用/摘要模板 | `templates/*.tpl` | 中性文本模板 | 替换模板文件，不改交付流程 |
| PPT 主题 | `templates/neutral_theme.json` | 中性主题、可编辑文字表格 + 图表底稿 | 企业视觉资产按主题文件替换 |

## 5. D01–D07 的处理方式

| PRD 项 | 基线（本次） | 仍需收集 / 不宣称 |
|---|---|---|
| D01 宿主与平台 | 工具与宿主解耦；先验证现有 OpenCode + macOS | 不宣称全部 Agent/平台已支持 |
| D02 来源 | 本地描述、文本、表格导出、Git + 统一远端输入边界 | 首批远端字段映射待补 |
| D03 方法与细则 | 三维初始规则 + 明确标注的通用方法参考 | 不配置虚构官方评分/权重/十一阶段统一标准 |
| D04 PPT | 真实 PPTX、中性主题、文字表格可编辑、图表底稿、独立渲染检查 | 企业资产/页面约束/字体待补；替换模板不改流程 |
| D05 汇总 | 摘要文件导入导出 + 汇总表 | 具体共享渠道由部门决定，不影响交换契约 |
| D06 试点 | E01–E12 + 规格场景验证能力 | 不虚构业务目标或试点结果 |
| D07 技术栈 | Python 3.11+、JSON、确定性数值、stdlib OOXML、可选独立渲染器 | 依赖锁定与各环境可用性进入支持矩阵；pip 不可用故内核零依赖 |

## 6. 验证原则

- 计算使用独立参考值（E05 见 `tests/fixtures/expected_values.json`），不由产品自证。
- 渲染检查缺失依赖 → 标记未执行/受限，不冒充通过。
- 人工校准（10.3）与真实成员试点须由人完成，本变更保留记录结构，不代填结论。
